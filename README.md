📊 Job Market Analysis Using Python and Power BI

📌 Project Overview
The Job Market Analysis project focuses on analysing job postings to understand employment trends, salary distributions, hiring companies, industries, and in-demand technical skills.

The project uses Python for data cleaning and analysis and Microsoft Power BI to create an interactive dashboard for visualising important insights from job-market data.

#🎯 Project Objectives
- Analyse job opportunities across different states.
- Identify companies with the highest number of job postings.
- Explore popular job titles and industries.
- Compare average salaries across states and job roles.
- Identify the most demanded technical skills.
- Understand the relationship between education qualifications and salaries.

🛠️ Tools and Technologies
* Tool                 |      Purpose                               
* CSV                  |      Dataset storage 
* Python               |      Data analysis 
* Pandas               |      Data cleaning and manipulation 
* Jupyter Notebook     |      Writing and executing Python code 
* Microsoft Power BI   |      Interactive dashboard and visualisation 

📂 Dataset Description
- Total Records: 742 job postings
- Total Columns: 41
- Dataset Format: CSV

The dataset contains information about companies, locations, job titles, industries, salary ranges, educational qualifications, and technical skills.

⚙️ Project Workflow
1. **Data Collection:** Imported the job-market dataset in CSV format.
2. **Data Cleaning:** Checked missing values, duplicate records, and data types.
3. **Data Preparation:** Used Python and Pandas to prepare the dataset for analysis.
4. **Exploratory Data Analysis:** Analysed job postings, salaries, companies, industries, and skills.
5. **Data Visualisation:** Created charts and KPI cards in Power BI.
6. **Dashboard Development:** Built an interactive dashboard with State and Industry filters.

📈 Key Analysis Performed
- State-wise job postings.
- Average salary by state.
- Top 10 hiring companies.
- Top 10 job titles.
- Top 5 industries.
- Most demanded skills (Python, SQL, Excel, AWS, Spark, and Tableau).
- Salary analysis based on education qualifications.
